# Solana Pulse MCP Server

Remote Model Context Protocol (MCP) server providing real-time Solana, DeFi, and trending crypto market pulse data and DEX spread metrics for AI agents.

## Live Remote Endpoint
- **Streamable HTTP / JSON-RPC URL:** `solana-pulse-mcp.gallonconnor2.workers.dev/mcp`

## Available Tools
- `get_crypto_market_pulse`: Live USD prices, 24h changes, and arbitrage volatility spreads for Solana, Ethereum, Jupiter, Raydium, and BONK.
- `get_trending_solana_tokens`: Real-time top trending tokens and market cap ranks across DEXs.
